# Astrea Correct

Astrea Correct is an AI-powered multilingual grammar correction and text enhancement system developed using Flutter, Flask, and PyTorch.

## Features

- Grammar Correction
- Translation
- Paraphrasing
- Vocabulary Enhancement
- Writing Assistance
- AI-powered Backend

## Tech Stack

### Frontend
- Flutter
- Firebase Authentication

### Backend
- Flask
- PyTorch
- Docker

## Project Structure

├── Frontend/
├── Backend/
